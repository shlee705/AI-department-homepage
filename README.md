# 미니 학과 홈페이지

전남대학교 인공지능학부를 참고한 React + Vite + Express 로컬 프로젝트입니다. 학부 소개는 짧게 요약했으며, 초기 공지사항은 기능 확인용 예시입니다. 교육과정은 전남대학교 인공지능학부의 2026학년도 편성표를 사용합니다. 채용정보는 빈 게시판에서 시작합니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 실행 명령의 순서는 `run dev`입니다.

개발 서버는 서버 코드 변경 시 자동으로 재시작됩니다. 재시작 후에는 다시 로그인합니다. 실행 명령 자체가 변경된 경우에는 기존 터미널에서 `Ctrl+C`로 종료한 뒤 다시 실행해 주세요.

## 테스트 계정

| 구분 | 학번 | 비밀번호 | 권한 |
| --- | --- | --- | --- |
| 관리자 | 261234 | admin | 일반·비밀 공지 작성, 공개 채용정보 등록, 공지·채용 수정·삭제, 모든 게시글 열람 |
| 학생 | 262626 | test | 일반 게시글 열람 |

로그인 창에서 두 계정을 확인하고 자동 입력할 수 있습니다. 회원가입은 없습니다. 미로그인 사용자와 학생 모두 비밀글 본문을 읽을 수 없습니다. 비밀글 제목은 홈과 목록에서 `[비밀글]`로 표시됩니다.

## 기능

- 홈 배너 슬라이드, 공지·채용 미리보기와 상세 페이지 연결
- 마우스·키보드·모바일을 지원하는 상단 펼침 메뉴
- 스크롤에 따라 나타나는 학과 소개, 전공별 교육과정 탭과 과목별 상세 설명 모달
- 게시판 분류, 제목 검색, 페이지 이동
- 서버 인증, 8시간 HttpOnly 세션 쿠키, 로그아웃
- 관리자 공지 작성, 비밀글, 상단 고정
- 관리자 채용정보 등록(기업·기관명, 분류, 마감일, 제목, 내용). 채용정보는 모두 공개이며 비밀글을 지원하지 않습니다.
- 공지사항·채용정보 상세 화면의 관리자 전용 `게시글 삭제` 버튼과 삭제 확인 창. 삭제 결과는 홈과 게시판에도 반영됩니다.
- 관리자 전용 `게시글 수정` 버튼으로 기존 내용을 불러와 수정합니다. 공지의 비밀글·상단 고정, 채용의 기업·기관명·마감일도 수정할 수 있습니다. 게시글 주소와 최초 등록일은 유지됩니다.
- 게시글을 `server/data/posts.json`에 저장하여 서버 재시작 후에도 유지

세션은 서버 메모리에 보관하므로 서버 재시작 후에는 다시 로그인합니다. 테스트용 계정을 안내하는 로컬 데모이며 실서비스 계정 관리 기능은 포함하지 않습니다. 비밀글의 권한은 UI와 별도로 서버 API에서 검증합니다.

## 검증 및 빌드

```powershell
npm.cmd test
npm.cmd run build
npm.cmd start
```

`start`는 빌드한 화면과 API를 같은 서버에서 제공합니다. 기본 포트는 5173이며 `PORT` 환경변수로 바꿀 수 있습니다. 게시글을 처음 상태로 되돌리려면 서버를 종료한 뒤 `server/data/posts.json`을 삭제합니다.

## 파일

- `src/main.jsx`: 화면, 라우팅, 로그인·공지 및 채용정보 작성
- `src/styles.css`: 반응형 디자인과 스크롤 등장 효과
- `server/app.mjs`: 로그인·권한·게시판 API
- `server/seed.mjs`: 초기 예시 게시글
- `server/app.test.mjs`: 인증·접근 제한·저장 검증
